# Changelog

Cambios destacados de cada versión de `agent-runtime`.

## [0.1.0] — versión inicial

- Primera versión identificada del proyecto, con API, UI nativa, SDK cliente y Memory integrada en el proceso de Runtime.
- La interfaz incorpora una navegación de conversaciones con secciones de activas y archivadas, y acciones de preferencias, configuración y nueva conversación.
- Se documentó cómo fijar la versión de las imágenes Docker publicadas mediante `AGENT_RUNTIME_VERSION`.
